### 안정성과 오류 수정
- 빈 페이지를 만들 때 크기를 확인합니다 (한 변 3~14,400pt). 잘못된 크기 때문에 화면이 깨지던 문제를 막습니다.
- 큰 도면(A0 등) 페이지의 미리보기·썸네일이 메모리를 너무 많이 쓰지 않도록 크기를 제한했습니다. 보통 크기의 페이지는 그대로입니다.
- 내보낸 PDF의 한글 파일 이름이 깨지지 않습니다.
- 자동 업데이트가 내려받는 설치 파일의 이름을 더 엄격하게 확인합니다.
- 큰 파일을 저장(PDF 내보내기, 한글 문서 저장)할 때 다운로드가 끊기지 않도록 고쳤습니다.
- 가림 영역 편집기에서 다른 페이지로 넘어갈 때 이전 페이지의 가림 영역이 잠시 남던 문제를 고쳤습니다.
