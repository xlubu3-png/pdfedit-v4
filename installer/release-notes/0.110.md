### 첫 화면에서도 오른쪽 클릭 메뉴
- 페이지 목록에서 페이지를 **오른쪽 클릭**하면 메뉴가 열립니다: 텍스트 편집 · 가림 영역 그리기 · 글자 인식(OCR) · 왼쪽/오른쪽으로 회전 · 페이지 복제 · 뒤에 빈 페이지 삽입 · 이 페이지만 추출 · 이 페이지 인쇄 · 선택 · 페이지 삭제
- 편집 화면에서는 페이지 바깥의 회색 부분을 오른쪽 클릭해도 쪽 메뉴가 열립니다 (‘여기에 텍스트 추가’는 페이지 위에서만).

### 모든 안내를 한글로
- 업데이트 안내와 릴리스 설명을 한글로 보여 줍니다.
- 앱이 꺼져 있을 때, 100MB가 넘는 파일을 열 때, 보관 기간이 지나 문서가 지워졌을 때, 업데이트를 확인하지 못했을 때 등의 오류도 영어 대신 한글로 알려 줍니다.

### 0.109에서 고친 점
- 큰 도면(A0 등) 페이지의 미리보기가 메모리를 너무 많이 쓰지 않도록 했습니다.
- 내보낸 PDF의 한글 파일 이름이 깨지지 않습니다.
- 큰 파일을 저장할 때 다운로드가 끊기지 않도록 고쳤습니다.
- 가림 영역 편집기에서 다른 페이지로 넘어갈 때 이전 페이지의 가림 영역이 잠시 남던 문제를 고쳤습니다.
