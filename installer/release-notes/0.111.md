### 오른쪽 클릭 메뉴가 열리지 않던 문제
- 브라우저 확장 프로그램(오른쪽 클릭 허용, 마우스 제스처 등)이 오른쪽 클릭을 가로채면 앱 메뉴 대신 브라우저 메뉴가 뜨던 문제를 고쳤습니다. 이제 앱이 오른쪽 클릭을 가장 먼저 받습니다.
- 확장 프로그램이 오른쪽 클릭을 완전히 막아도, 버튼을 놓으면 앱 메뉴가 열리고 메뉴 아래에 그 이유를 알려 줍니다.
- 편집 화면에서는 어디를 오른쪽 클릭해도(페이지, 페이지 바깥 회색 부분, 위쪽 리본과 안내 막대) 앱 메뉴가 열립니다.
- 키보드로는 Shift+F10 또는 메뉴 키로 같은 메뉴를 열 수 있습니다.
