### PDF 용량 줄이기
- 위쪽 '내보내기'의 **용량 줄이기**를 켜고 내보내면, 스캔·사진 같은 그림을 150dpi로 다시 저장해 파일을 작게 만듭니다(메일 첨부·서류 제출용). 글자와 표·도형은 그대로이고, 작은 그림·흑백 스캔·투명한 그림은 손대지 않습니다.
- 내보낸 뒤 줄인 그림 수와 줄어든 용량을 알려 줍니다. '이미지로 변환'과 함께 켜면 페이지 그림을 낮은 해상도로 만듭니다.

### 설치 파일을 GitHub에서 만듭니다
- 새 버전의 설치 파일을 GitHub의 Windows 서버에서 만들어 릴리스로 올립니다. 쓰시는 방법은 그대로입니다(업데이트 안내 → 지금 업데이트).
