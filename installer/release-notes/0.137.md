### 문제 보고 버튼
- 첫 화면 아래 **문제 보고**를 누르면 프로그램 기록 파일(app.log와 지난 기록)과 PC·프로그램 정보(버전, Windows, 메모리, 글꼴 수, 설정, 빨리 켜기 상태)를 **ZIP 하나(WINTECH_문제보고_날짜_시각.zip)로 다운로드 폴더에 내려받습니다.** 프로그램이 이상할 때 이 파일을 담당자에게 보내 주세요.
- 문서와 문서 내용은 들어 있지 않습니다.

### 파일마다 처리 (여러 파일 한 번에)
- 위 메뉴의 **파일마다 처리**: 연 파일들을 골라 **글자 인식(방향·기울기 바로잡기 포함)과 PDF 용량 줄이기**를 하고, **파일마다 따로 PDF·엑셀 파일로 저장**합니다. 여러 개면 `일괄처리_날짜_시각.zip` 하나로 내려받고, 하나면 그 파일 그대로 받습니다.
- 저장 파일 이름은 원래 파일 이름을 따릅니다(이름이 같으면 "(2)"를 붙임). 인식 중에는 '중지'로 멈출 수 있습니다.
- 암호가 걸려 있던 파일도 암호 없이 저장됩니다(암호가 필요하면 내보내기를 쓰세요).

### 표 칸 직접 바로잡기
- 자동으로 찾은 표가 틀렸거나 표를 못 찾았을 때, 편집 화면에서 오른쪽 버튼 → **표 칸 바로잡기…** 로 직접 고칠 수 있습니다.
  - **선 옮기기:** 칸 선을 끌어 옮기고, 두 번 클릭해 지웁니다.
  - **세로선 넣기 / 가로선 넣기:** 표 안을 클릭한 곳에 칸·줄 경계를 넣습니다.
  - **새 표 그리기:** 표가 될 곳을 끌어 그리면 안의 글자 줄과 칸에 맞춰 자동으로 나눠 줍니다.
  - **완료**로 저장하고, **자동으로 되돌리기**로 쪽에서 찾은 표를 다시 씁니다.
- 바로잡은 표는 그 쪽에 저장되어(앱을 다시 켜도, 쪽을 복제해도 남음) **엑셀 파일로 저장, 표 모양으로 복사, 쪽 목록의 엑셀 저장**에 모두 쓰입니다.

### 스캔 문서는 열자마자 글자 인식
- 글자가 없는 **스캔 PDF를 열면 묻지 않고 바로 글자를 인식합니다**(방향·기울기 바로잡기 포함, 쪽당 2초쯤). 위에 진행 상황이 보이고 **'중지'** 로 멈출 수 있습니다.
- 첫 화면 아래 **글자 인식 설정**에서 "스캔 문서를 열면 묻지 않고 바로 글자 인식하기"를 끄면 전처럼 "글자 인식 / 나중에"를 묻습니다(기본은 켬).

### 뒤집히거나 누운 스캔도 바로, 흐린 스캔은 더 잘 읽기
- **거꾸로(180°) 또는 옆으로 누워(90°) 스캔된 쪽을 글자 인식할 때 알아서 바로 돌립니다.** 기울기 바로잡기와 함께 되며, Ctrl+Z로 되돌릴 수 있습니다. 쪽 목록에서 직접 돌려 둔 쪽은 방향을 건드리지 않습니다.
- 쪽 목록 오른쪽 버튼 메뉴가 **방향·기울기 바로잡기 (스캔)** 으로 바뀌었습니다.
- **흐린 스캔(팩스, 복사본, 연한 글씨)과 잡티가 많은 스캔**은 글자를 읽을 때만 대비를 높이고 잡티를 지워 인식률을 높입니다. 쪽 그림 자체는 바뀌지 않습니다. 깨끗한 스캔은 전과 똑같이 읽습니다.

### 스캔한 쪽의 기울기 바로잡기
- **글자 인식을 누르면 비스듬히 스캔된 쪽(0.25°~5°)을 먼저 바로 세운 뒤 읽습니다.** 인식이 더 정확해지고, 글자 선택·엑셀 저장·고쳐 쓰기·찾기·가리기도 줄에 맞게 됩니다. 쪽 목록·스캔 안내·편집 화면 어디서 인식해도 같습니다.
- 쪽 그림을 다시 압축하지 않고 쪽을 그리는 방향만 돌리므로 화질과 용량이 그대로입니다. **Ctrl+Z로 되돌릴 수 있습니다.** 글자로 된 PDF 쪽은 건드리지 않습니다.
- 쪽 목록에서 오른쪽 버튼 → **기울기 바로잡기 (스캔)**: 글자 인식 없이 바로잡기만 합니다(고른 쪽 여러 장도 한 번에). 이미 글자 인식을 한 쪽은 바로잡은 뒤 다시 인식합니다.
- 첫 화면 아래 **글자 인식 설정**에서 "글자 인식할 때 기운 스캔 쪽을 먼저 바로잡기"를 끌 수 있습니다(기본은 켬).

### 기록 파일 정리
- 기록 파일(`app.log`)에 PC 글꼴을 읽을 때마다 나오던 쓸모없는 경고 수십 줄을 더 남기지 않습니다. 문제가 생겼을 때 원인을 찾기 쉬워집니다.
- 기록 파일의 시작 줄에 실제 프로그램 버전(예: v0.131)이 찍힙니다(전에는 v0.1.0).
