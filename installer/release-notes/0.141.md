### 개인정보 찾아 가리기 보강
- **찾는 종류가 늘었습니다:** 차량번호(12가3456, 서울34나5678), **차대번호**(스캔에서 띄어 읽힌 것도), 국제 표기 전화번호(+82 10-…), 법인등록번호(검증 숫자 확인). 자동차등록증 스캔에서 차량번호·차대번호를 찾습니다.
- **사람 이름과 주소도 찾을 수 있습니다(처음에는 꺼짐):** 이름은 "성명·담당자·신청인 :" 같은 칸 뒤에 있을 때만 찾아 이름 글자만 가리고, 주소는 도로명+건물번호(또는 동·번지)까지 있을 때만 찾아 시·군·구 뒤부터 가립니다. 회사 견적서의 회사 주소·담당자도 걸리므로 필요할 때 켜서 쓰세요.
- **'개인정보 가리기' 창을 열면 바로 찾아** 목록을 보여 줍니다. 확인하고 "선택한 N곳 가리기"를 누르면 됩니다.

### 견적서 금액 검산
- 편집 화면에서 오른쪽 버튼 → **금액 검산 (수량×단가·합계·세액)**: 쪽의 표에서 **수량 × 단가 = 금액**, **품목 금액의 합 = 합계(소계·계)**, **부가세 = 공급가액의 10%**, **총액 = 공급가액 + 세액**, 그리고 **표 위에 적힌 견적 금액 = 표의 합계**인지 계산해 봅니다.
- 맞지 않는 칸은 **빨간 상자**로 표시하고, 무엇이 얼마여야 하는지 알려 줍니다. 맞으면 "이상 없습니다"라고 알려 줍니다.
- 수량·단가·금액(공급가액)·세액 같은 제목이 있는 표만 검산합니다. 스캔 견적서는 글자 인식 후에, 표를 잘못 찾았으면 '표 칸 바로잡기' 후에 쓰세요. 합계 행이 표 아래에 따로 떨어져 있어도 이어서 셉니다.

### 스캔 표 인식 개선
- **표의 칸 선을 글자로 잘못 읽던 것을 줄였습니다.** 인식할 줄에 칸 테두리(겹선·점선 포함)나 옆 칸·위아래 줄 글자 끝이 걸치면, 그것을 지운 그림으로도 한 번 더 읽어 더 확실한 쪽을 씁니다.
- **소수점이 빠진 숫자를 다시 읽습니다.** 쪽의 숫자 대부분에 소수점이 있는데 점이 빠진 숫자("12.1" → "121")가 있으면, 옆으로 늘려 다시 읽어 점을 되찾습니다(같은 숫자일 때만).
- **한 칸에 여러 줄로 쌓인 품목과 금액을 엑셀에서 행마다 나눕니다.** 견적서처럼 품목 여러 줄과 금액 여러 줄이 표의 한 행에 들어 있으면, 엑셀로 저장·복사할 때 품목마다 한 행씩 들어갑니다.
