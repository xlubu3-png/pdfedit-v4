### 견적서 표 비교가 더 정확해졌습니다
- **같은 품명이 여러 번 나오는 견적서:** "앵글 30x30 / 앵글 50x50"처럼 이름이 같은 품목은 순서가 아니라 **규격·수량·단가가 가장 비슷한 줄끼리** 짝지어 비교합니다. 2차 견적에서 줄 순서가 바뀌어도 엉뚱한 줄과 비교하지 않습니다. 결과에는 "앵글 (2)"처럼 몇 번째 줄인지 표시합니다.
- **표가 여러 개인 문서:** 서로 다른 표에 같은 이름의 항목(예: 설치비)이 있으면 뒤 표의 것만 비교되던 문제를 고쳤습니다. 이제 모든 표의 항목을 비교합니다.
