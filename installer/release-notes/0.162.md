### 뒤집히거나 누운 스캔도 빠르게
- 0.160에서 바로 선 스캔은 빨라졌지만, 뒤집히거나 누운 쪽은 한 번 다 읽어 본 뒤에야 돌려서 다시 읽느라 느려졌습니다. 이제 글자 인식이 **처음 찾은 글자 줄 몇 개로 방향부터 판별**하고, 뒤집히거나 누운 쪽은 다 읽지 않고 바로 돌려서 읽습니다(시험한 3쪽: 24초 → 14초). 바로 선 쪽의 속도는 그대로입니다.

### 설치 파일을 만들 때 Windows에서도 자동 시험
- 지금까지 자동 시험은 Linux에서만 돌았습니다. 이제 설치 파일을 만들 때 **설치될 프로그램 그대로**(함께 들어가는 Java 포함)를 Windows에서 켜고, Edge로 화면 시험 전체를 돌립니다. 하나라도 실패하면 릴리스로 올라가지 않습니다.
- Windows에서만 생길 수 있는 문제(글꼴, 파일 경로, Office 부르기, 빠진 Java 부품)를 업데이트 전에 잡습니다. MS Office로 문서를 바꾸는 부분은 시험 서버에 Office가 없어 "Office가 없을 때의 안내"까지만 확인합니다.

### 새로 설치한 PC에서 첫 문서도 빠르게
- 문서에 들어 있지 않은 글꼴을 PC에서 찾으려고 PDF 부품이 **처음 한 번 PC의 글꼴 파일을 모두 읽어 목록을 만드는데**, 새로 설치한 PC에서는 첫 문서를 열 때 이 일을 하느라 오래 기다렸습니다. 이제 앱이 켜지자마자 뒤에서 미리 만들어 둡니다.
