### 문서를 열 때 CPU 덜 쓰기
문서를 열거나 스캔을 인식할 때 PC 전체가 느려지던 것을 줄였습니다.
- **문서를 열 때 미리 분석하는 쪽을 앞쪽 6쪽으로 줄였습니다.** 지금까지는 텍스트 편집을 빨리 열려고 300쪽까지 모든 쪽을 뒤에서 미리 분석해, 큰 문서를 열면 몇 분 동안 CPU를 썼습니다. 편집 중인 쪽의 앞뒤 쪽은 지금처럼 미리 준비합니다(시험한 120쪽 문서: 열고 90초 동안 쓴 CPU 13초 → 9초). 멀리 떨어진 쪽을 처음 편집할 때 1초 안팎 기다릴 수 있습니다.
- **글자 인식(OCR)이 CPU를 절반만 씁니다.** 스캔을 열면 뒤에서 글자 인식이 돌아가는데, 지금까지는 CPU 코어를 모두 써서 그동안 PC와 화면이 느려졌습니다. 이제 코어의 절반(최소 2개)만 씁니다(4코어 PC: 평균 3.7코어 → 2.2코어). 대신 글자 인식은 조금 느려집니다(시험한 3쪽: 11초 → 14초).
