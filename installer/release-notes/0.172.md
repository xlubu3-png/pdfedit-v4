### 켜고 가만히 있을 때 메모리 크게 줄이기
- 프로그램을 켤 때 준비 작업(글꼴 목록 읽기, 글꼴 분석 불러오기 등)에 쓴 메모리를 정리하지 않고 계속 잡아 두고 있었습니다. 이제 켜고 20초 뒤 한 번 정리해 Windows에 돌려줍니다.
- 시험용 PC에서 켜고 가만히 있을 때: **약 540MB → 약 190MB**.

### 페이지 목록 미리보기 그림을 가볍게
- 페이지 목록의 미리보기 그림을 PNG 대신 JPEG로 만듭니다. 스캔 문서는 그림 크기가 절반 정도라(150쪽 스캔: 5.4MB → 2.7MB) 긴 문서의 목록이 더 빨리 채워집니다.
- 참고: 브라우저 탭이 쓰는 메모리는 그림 형식과 상관없이 거의 같습니다(150쪽 스캔을 끝까지 넘겼을 때 약 250MB, 그중 약 130MB는 빈 화면일 때도 쓰는 몫).

0.168~0.172를 합치면 켜고 가만히 있을 때 **약 1,000MB → 약 190MB**, 스캔을 다룬 뒤 몇 분 지나서 약 2,300MB → 약 430~580MB입니다(시험용 PC 기준).
